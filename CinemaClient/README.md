# CinemaClient
Mở pom.xml bằng IntelliJ, dùng JDK 21+ và chạy vn.khoa.cinema.client.ClientMain.
Chạy ngay bản đã build: run.bat (Windows) hoặc sh run.sh (Linux).
Server phải đang chạy trong cùng LAN; client tự tìm server và tự chọn cổng callback.
Mã thư viện chung + source JAR đã kèm trong repository/. Không cần tự install common.
Hướng dẫn đầy đủ ở ../README.md và ../docs/.
